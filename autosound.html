Acoustic & Multimodal AI Architecture

Trinity Venture Studio의
4대 핵심 엔지니어링 엔진

아이디어에서 상용 제품까지 단 2주 만에 고밀도로 완성된 풀스택 기술 명세입니다.

NVH 광대역 오디오 녹음 & DSP 합성 엔진

스마트폰 기본 잡음 제거(Noise Suppression) 필터가 기계 마찰음을 잡음으로 오인해 소거하는 문제를 해결하기 위해 NVH 제약조건 바이패스 파이프라인을 구축했습니다. 실내 테스트 환경을 위해 8종 이상 소음 브라우저 물리 DSP 합성기를 내장했습니다.

Web Audio API AnalyserNode FFT DSP Synthesizer iOS Safari CriOS Bridge

Multimodal Contextual AI 추론

소리만 분석하지 않고 제조사, 모델, 연식, 유종, 주행거리, 14종 상황별 증상 벡터를 결합하여 Google Gemini Flash에 동시 바인딩합니다. Grammar-Based JSON 스키마를 강제 디코딩하여 1.5초 만에 정형화된 원인과 메커니즘을 산출합니다.

Gemini Flash Multimodal Grammar JSON Schema Domain Heuristics Aftermarket Part Mapping

Zero-DB 무손실 상태 직렬화 엔진

진단 결과 공유 시 중앙 데이터베이스 조회 없이 LZ-String 무손실 압축 알고리즘을 사용해 URL 파라미터(?p=...) 자체에 전체 진단 상태를 패키징합니다. 서버 DB 비용 0원으로 수백만 건의 카카오톡 바이럴 링크를 영구 유지합니다.

LZ-String Compression Zero Server DB Cost Permanent URI Link Zustand Session Sync

RLHF 자가 고도화 플라이휠

차주들의 1초 진단 일치 피드백과 카센터 실제 정비 후 판명된 부품명(Ground Truth) 및 실비 지출 내역을 수집합니다. 수집된 실제 정비 데이터는 지속적인 도메인 규칙 보정 및 AI 모델 미세조정 데이터셋으로 자동 선순환됩니다.
