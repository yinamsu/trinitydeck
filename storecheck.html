Key Value Proposition

"얼마나 버는가"가 아니라
"왜 망하는가"를 짚어내는 3대 킬러 기능

기존 상권 분석 플랫폼의 장밋빛 매출 추정을 배제하고, 소상공인의 생존을 위협하는 숨겨진 리스크를 선제 격리합니다.

킬러 기능 1: '자리 징크스' (Graveyard Spot) 추적

같은 상권이라도 유독 사각지대나 동선 단절로 인해 임차인이 6개월~1년 주기로 계속 바뀌는 자리가 있습니다. 건축물관리번호(bldMgtNo)와 층/호실을 결합한 공간 식별자(location_id)를 생성하여 연쇄 폐업 횟수와 평균 생존 주기를 G-Index로 수치화합니다.

G-Index Scoring Chained Closure Tracker location_id Spatial Key Graveyard Danger Alert

킬러 기능 2: 건축물 행정 리스크 '레드플래그' 오토 오딧

계약 직전까지 임대인이 숨기는 불법 증축·위반건축물 등재 여부, 용도지역별 정화조 용량 및 정화구역 제한, 직전 영업장의 영업정지 등 행정처분 승계 위험을 공공 건축물대장 오픈 API로 3초 만에 자동 전수 감사(Audit)합니다.

Architectural Ledger Audit Violation Building Detection Zoning Verification Administrative Risk Purge

킬러 기능 3: 시드머니 기준 '생존 런웨이' & BEP 계산기

예비 창업자의 총 가용자본금, 인테리어/가맹비 등 초기 매몰비용, 월 임대료와 고정 인건비를 입력받아, 매출이 0원일 때 버틸 수 있는 '최악의 런웨이'와 손익분기점(BEP) 달성을 위한 일/월 최소 필요 매출액을 과학적으로 산출합니다.

Survival Runway Calc BEP Breakeven Engine Fixed Cost Stress-Test Realistic Financial Planning

F1~F4: 주소 지오코딩 & 국토부 임대료 실거래가 연동

도로명/지번 주소 입력 즉시 위·경도 정밀 변환 후 Leaflet 인터랙티브 맵에 500m 분석 반경을 렌더링합니다. 국토부 상업용 부동산 실거래가 임대료와 소진공 점포 상태(영업중/1년내신규/1년내폐업)를 오버레이하여 금융권 제출용 1-Page PDF로 원클릭 출력합니다.

Address Geocoder MOLIT Commercial Rent API Leaflet / Kakao Maps 1-Page PDF Export
Data Pipeline & Engineering

PostGIS 공간 인덱싱 기반의
초고속 비동기 배치 파이프라인

공공데이터포털(data.go.kr)의 지연 응답과 월별 갱신 주기를 극복하기 위해 비동기 수집 워커와 PostGIS 공간 쿼리를 결합했습니다.

Python FastAPI & 비동기 Ingestion Worker

Python asyncio와 httpx를 활용하여 시군구코드(signguCd) 및 업종분류코드(indsLclsCd) 단위로 분할된 대용량 공공데이터를 비동기 병렬 수집합니다. Pydantic 2.0 스키마 검증을 거쳐 데이터 결함을 원천 차단합니다.

Python FastAPI asyncio + httpx Pydantic v2 Schema Async Worker

PostgreSQL 15 + PostGIS 공간 데이터베이스

GIST 공간 인덱스를 활용하여 `ST_DWithin` 반경 500m 공간 쿼리를 0.05초 만에 처리합니다. 매월 갱신되는 점포 데이터는 `INSERT ... ON CONFLICT (bizes_id) DO UPDATE` 업서트 전략으로 무중단 동기화됩니다.

PostgreSQL 15 PostGIS GIST Index ST_DWithin 500m Query Zero-Downtime Upsert

Next.js 15 App Router & Leaflet 동적 렌더링

Next.js 15의 SSR 환경에서 브라우저 전용 Leaflet 맵 객체가 충돌하지 않도록 Dynamic Import 컴포넌트 래퍼를 구축했습니다. 점포 유형별 커스텀 SVG 마커 클러스터링과 반응형 사이드패널을 매끄럽게 연결합니다.

Next.js 15 App Router Leaflet Dynamic Wrapper Custom SVG Markers Tailwind CSS Responsive

소상공인 정책자금 신청, 청년창업 사관학교, 시중은행 소상공인 대출 심사에 즉시 첨부할 수 있는 A4 1페이지 규격의 상권 리스크 진단서와 생존율 분석표를 웹 브라우저 네이티브 인쇄 규격(@media print)으로 렌더링합니다.

End-to-End Workflow

주소 입력부터 리포트 발급까지
단 4단계 상권 오딧 프로세스

복잡한 부동산 공문서나 통계청 데이터를 읽지 못해도 누구나 30초 만에 상권의 급소를 파악합니다.

STEP 01
주소 & 업종 선택
검토 중인 점포의 도로명/지번 주소와 층·호실, 희망 창업 업종(카페, 음식점, 미용 등)을 입력합니다.
STEP 02
가용 자본 & 고정비 입력
총 시드머니, 인테리어 매몰비용, 예상 월 임대료와 인건비를 기입하여 생존 런웨이 시뮬레이션을 준비합니다.
STEP 03
500m 반경 X-Ray 진단
PostGIS 공간 쿼리로 주변 개·폐업 밀집도, 자리 징크스(G-Index), 건축물대장 레드플래그를 즉시 판정합니다.
STEP 04
1-Page PDF 리포트 출력
위험 등급 판정표, 생존 런웨이 개월 수, BEP 일매출이 정리된 공식 분석 리포트를 PDF로 즉각 출력합니다.
